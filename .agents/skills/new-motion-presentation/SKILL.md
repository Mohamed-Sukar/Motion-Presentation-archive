# New Motion Presentation (`/new-motion-presentation`)

Create an original, high-creativity **interactive motion-graphics presentation** from scratch using `/motion-reel`'s pure code-drawn rendering architecture (`window.seek(t)`), complete with **Rest-Pose Idle Motion Loops** (`XX_loop.mp4`), **expressive transitions** (`XX-YY_transition.mp4`), and **`presentation.json`** for native one-drop playback and surgical AI editing inside **Motion Presentation Studio**.

> **Scope vs `/animate-slides`:**
> - Use **`/animate-slides`** when the user *already has* finished slide images (`01.png`, `02.png`, ...) and wants constrained, faithful motion transitions between those exact slides.
> - Use **`/new-motion-presentation`** when creating a presentation **from scratch** (a topic, script, product URL, or brief) with full creative freedom over art direction, typography, data visuals, Idle Motion Loops, and kinetic transitions.

---

## Stage 1: Content Lock (`outline.md`)

Never mix copywriting drift with visual exploration. Lock the narrative structure first:

1. Extract or propose a crisp slide-by-slide outline (`docs/outline.md`):
   - Slide number & semantic title (e.g., `01 — Opening Hook`, `02 — Core Architecture`, ...)
   - Exact headline + concise supporting points (readable from the back of an auditorium)
   - Whether the slide warrants an **Idle Motion Loop** (`idleLoop: true/false`) based on clear criteria:
     - **YES (`XX_loop.mp4`):** Hero cover slides, animated system/architecture flow diagrams, live metric/pulse cards, ambient 3D/geometric focal visuals.
     - **NO (static `XX_frame.png`):** Dense bullet/code/reading slides where background motion would distract from comprehension.
2. Present `docs/outline.md` to the user for quick approval. Once confirmed, keep core text locked unless the user requests an edit.

---

## Stage 2: Creative Direction Proposals (2–3 Distinct Concepts)

To unlock genuine creative variety for the same locked content, propose **2 to 3 distinct visual & kinetic directions** before full rendering:

- **Direction A — e.g., Kinetic Typography & Swiss Grid:** High-contrast editorial layout, bold scale shifts, crisp ink-and-paper or deep-slate surfaces, spring-driven word locks.
- **Direction B — e.g., Isometric 3D & Data Flow:** Depth-layered cards, subtle perspective camera sweeps, glowing signal pulses along connectors in Idle Loops.
- **Direction C — e.g., Atmospheric Glass & Spatial Canvas:** Layered dark-mode surfaces, radial ambient light fields, log-space camera dollies between focal zones.

Render quick static PNG previews (e.g., 2–3 key slides per direction) or describe the palette, typography, and loop choreography clearly so the user chooses one direction before rendering all videos.

## Stage 3: Modular Architecture (`scenes/`, `loops/`, `transitions/`)

Read `C:\Users\Mohamed\.gemini\config\plugins\motion-reel\skills\motion-reel\SKILL.md` and organize the project workspace (e.g., `reels/<project-slug>/`) using **shared slide drawing modules** so future surgical edits automatically propagate:

```text
reels/<project-slug>/
├── docs/
│   └── outline.md
├── scenes/
│   ├── slide_01.js          # Exports drawSlide01(ctx, state)
│   ├── slide_02.js          # Exports drawSlide02(ctx, state)
│   └── ...
├── loops/
│   ├── loop_01.js           # Imports drawSlide01 + periodic ambient motion
│   └── ...
├── transitions/
│   ├── t01_02/              # Imports drawSlide01 (t=0) & drawSlide02 (t=duration)
│   └── ...
└── out/<project-slug>/presentation/
    ├── presentation.json    # Native Motion Presentation Studio contract
    ├── 01_frame.png
    ├── 01_loop.mp4          # Optional Rest-Pose Idle Loop
    ├── 01-02_transition.mp4
    └── ...
```

### Mandatory Contracts
1. **Shared Slide Module (`scenes/slide_0N.js`):**
   - Renders the exact rest pose (`0N_frame.png`) at `state = defaultRestState` and accepts parameterization (offset, scale, alpha, reveal progress, ambient phase) for transitions and loops.
2. **Rest-Pose Contract for Idle Loops (`loops/loop_0N.js` -> `0N_loop.mp4`):**
   - **Boundary match:** At `t = 0` and `t = duration` (and periodic `exitPointsSec`), the canvas MUST match `0N_frame.png` pixel-faithfully.
   - **Typography stability:** Keep headlines, numbers, and body copy rock-steady and crisp; animate only ambient background motion, subtle floating cards, connector signal pulses, or breathing accents using periodic functions (`Math.sin(2 * Math.PI * t / duration)`).
   - **Audio-free:** Silent H.264 `yuv420p` (`60 fps`, `--video-only`) unless explicitly requested.
3. **Transition Continuity Contract (`0N-0(N+1)_transition.mp4`):**
   - **At `t = 0`:** exact match to `0N_frame.png`.
   - **During `0 < t < duration`:** expressive choreography (morphs, camera dollies in log space, staggered springs, element handoffs — never generic crossfades).
   - **At `t = duration`:** exact match to `0(N+1)_frame.png` with zero drift.
4. **Critique & Visual Verification:**
   - Verify `--at 0`, mid-motion `--strip`, and `--at <duration>` for every loop and transition against `0N_frame.png` / `0(N+1)_frame.png` before delivering.

## Stage 4: Export `presentation.json` & Deliver Ready for Motion Presentation Studio

In the presentation output folder (`out/<project-slug>/presentation/`), write:
- Ordered PNGs: `01_frame.png`, `02_frame.png`, ...
- Idle Loops (for looped slides): `01_loop.mp4`, ...
- Transition Videos (60 fps H.264 `yuv420p`, silent by default): `01-02_transition.mp4`, ...
- Native **`presentation.json`** manifest:

```json
{
  "skill": "new-motion-presentation",
  "title": "<Presentation Title>",
  "aspectRatio": "16:9",
  "projectRootPath": "<absolute path to reels/<project-slug>>",
  "outputDirPath": "<absolute path to out/<project-slug>/presentation>",
  "creativeDirection": "<Chosen Direction Name>",
  "slides": [
    {
      "index": 1,
      "title": "Opening Hook",
      "notes": "Presenter talking points for slide 1...",
      "frameFile": "01_frame.png",
      "idleLoopFile": "01_loop.mp4",
      "transitionVideoFile": "01-02_transition.mp4",
      "slideCodeFile": "scenes/slide_01.js",
      "idleLoopCodeFile": "loops/loop_01.js",
      "transitionCodeFile": "transitions/t01_02/film.js",
      "exitPointsSec": [0, 1.5, 3.0]
    }
  ]
}
```

## Handling Surgical Edits from Motion Presentation Studio

When the user pastes a **Surgical AI Edit Prompt** generated by Motion Presentation Studio's Inspector:
1. Respect the exact `Project Root Path`, `Output Directory`, `Target Scope`, and `Source Code Files` specified in the prompt.
2. **Respect "Do Not Touch":** Only edit and re-render the affected code module(s) and output asset(s) listed in `Affected Output Assets`.
3. If `Slide N` (`scenes/slide_0N.js`) was modified, automatically re-render:
   - `0N_frame.png`
   - `0(N-1)-0N_transition.mp4` (if `N > 1`)
   - `0N_loop.mp4` (if slide `N` has an Idle Loop)
   - `0N-0(N+1)_transition.mp4` (if `N < totalSlides`)
4. Update `presentation.json` if titles, notes, or new loop files were added, then verify the updated frames with `ffprobe` and visual checks.
